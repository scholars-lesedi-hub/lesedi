How OTP and payment confirmation must work

1. Create transaction on the secure server.
The server creates a unique payment reference and sends the customer to the provider's official checkout or approved payment flow.
2. Customer authorises payment with the provider.
For Orange Money Web Payment, the customer obtains the temporary OTP using the official Orange Money USSD process and enters it only in the approved provider payment flow. Never ask for the customer's wallet PIN or secret code.
3. Verify payment server-to-server.
A signed provider callback / webhook or authenticated transaction lookup confirms success. Only then should the platform activate the package and issue access.
4. MyZakaPay QR.
MyZakaPay's public merchant flow supports scanning a merchant QR. A website API / OTP flow must be confirmed directly with Mascom before automating payment status.

STEAM Assessments

Choose a subject and start a short STEAM quiz, test or exam. The Agriculture school garden unit includes labelled STEAM questions.

Teacher introduction to STEAM

A short introduction for teachers and tutors. No certificate is awarded.

1. Start with a practical problem

Use the Standard 5 school garden unit. Ask learners how they could water seedlings using a recycled bottle and a limited amount of water.

2. Label the skill learners demonstrate

Use Science for investigating, Technology for selecting or using tools, Engineering for designing and testing, Arts for purposeful visual communication, and Mathematics for measuring, calculating or interpreting data. Add a secondary label only when the question assesses that skill too.

3. Choose the evidence and marking method

The quiz checks three objective skills. The test adds a design task. The exam adds visual communication and a design-and-calculation task. Objective items are automatically marked. Use the rubrics below to award marks for written work.

4. Review before publishing

Use the Examination Studio to prepare a school assessment. Check the level, question wording, answer key and rubric before approving and publishing it.

Worked examples for teacher marking

Engineering marking example

A recycled bottle drip system empties too quickly. Describe one design change and a fair test to check whether it works.

3 marks. Award 1 for a feasible design change, 1 for keeping relevant conditions the same, and 1 for comparing the time or water delivered.

Sample full-credit response. Use a smaller outlet. Start both bottles with the same amount of water and keep them at the same height. Time how long each takes to deliver 250 mL.

Arts marking example

Plan a three-panel illustrated guide showing younger learners how to fill, place and check the bottle. Describe what each panel shows and how you would make the order clear.

3 marks. Award 1 for covering all three steps in order, 1 for visuals that clarify each step, and 1 for a clear sequence cue such as arrows or numbers.

Sample full-credit response. Panel 1 shows water pouring into the bottle, panel 2 shows the bottle beside a seedling, and panel 3 shows a learner checking the water level. Large numbers and arrows show the order.

Engineering + Mathematics marking example

A bottle delivers 250 mL in 20 minutes. If it runs at the same rate, how much will it deliver in 60 minutes? Explain how you would check that prediction with your prototype.

3 marks. Award 1 for 750 mL, 1 for showing three 20-minute intervals or equivalent reasoning, and 1 for a feasible 60-minute test using a measuring container.

Sample full-credit response. 60 ÷ 20 = 3, so 3 × 250 mL = 750 mL. Run the bottle for 60 minutes with enough water and measure what collects in a marked jug.

Platform Setup & Roadmap

What is needed to turn this prototype into a real online service.

Recommended production architecture

  1. Frontend: responsive web app for computers, tablets and smartphones.
  2. Backend and database: secure user accounts, roles, schools, classes, resources and results.
  3. Document processing: PDF/Word extraction, OCR for scanned images and page-by-page review.
  4. AI services: secure server-side integration for lesson plans, summaries and question drafting.
  5. Examination engine: timers, access codes, question banks, auto-marking and teacher moderation.
  6. Payments: Orange Money Web Payment, MyZakaPay merchant QR and an approved international Visa/Mastercard gateway, all verified server-side before package activation.
  7. Security: encrypted transport, secure password hashing, backups, audit logs and permissions.
Never use browser localStorage as the production source of truth for passwords, payment status, access codes, exam answers or learner records.
