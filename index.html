My Offline Learning Library

Connect once, download selected resources, then learn without using more data.

1. Download your library

This portable HTML library keeps your downloaded learning resources together on the device. It has no account login or internet dependency.

Open library while connected. To use later without internet, download it and open the saved file. Online and downloaded copies may use separate browser storage.

2. Save learning resources while connected

Open an available activity and choose Download for Offline Use. Its pictures and content are included. Save adult guides separately.

Ready-made lesson packs already have Save Editable Copy after opening a pack; that saved HTML can also be imported into your offline library.

3. Open without internet

Open your downloaded library HTML, import the downloaded activity/guide/notes HTML files, and choose Open. Original files also work directly in a browser. Saved resources are labelled Ready offline. Keep originals as backups.

Practice feedback and responses are local to the open activity. They do not create cloud exam results. Use the resource’s print button to retain responses where supported; prepared editable documents have Save Edited Copy.

What still needs internet?

AI creation, OCR, new authoring requests, package changes, sending messages, forum updates and online exam joining need a connection. Download their prepared outputs where an export is offered. No offline AI processing or automatic background result upload is added.

Existing package checks and Explorer allowances apply before downloads. Downloaded copies can be retained; they cannot reliably expire offline. Keep adult guides and teacher files separate from children’s copies. Browser data clearing or moving the library file can affect stored copies, so keep original files.

Learner Codes & Online Class Access

Create your teacher/member account once. Generate a reusable L1, L2, L3 label for each learner, then share an exam code for each test. Learners do not need accounts for this route.

1. Generate codes for your class

A new class of 30 learners gets L1 to L30. Keep a private list such as Kabelo Thabo = L1. Each label has a private six-digit PIN for online joining. Give each child only their own label and PIN. Generating again continues the numbering; it does not replace or renumber existing labels.

2. Choose a test and create its exam code

For a ready-made test, select Share Online with Learner Codes on its card. For your own draft, select Create Online Class Access in Studio. Previously created offline snapshots are also available below.

Only active learner labels in the selected class can join with their private PIN. Access ends by the earlier of your chosen date or your package expiry. Each learner gets one attempt per exam code. A new exam code gives a new attempt.

3. View learner results

Select View results beside an exam code above. The score is calculated on the server. Learner codes do not independently verify who answered; supervise assessments and keep codes private.

Join an Exam with Codes

No learner account needed. Ask your teacher for the exam code, your short learner label (such as L1) and your private six-digit PIN.

Keep the internet connected while answering. Changes save online; wait for “Answers saved online” before closing. After a refresh, re-enter the same exam code, label and PIN to resume. When a deadline passes, marking uses the last answers saved before it. Do not share your learner code.

Hybrid Offline Examination Centre

Prepare online. Answer offline. Collect, mark and reconnect.

Digital, offline and printable assessments

Use personal or shared devices. Download a self-contained learner HTML file; it runs without internet or learner login. Ready-made downloads keep their multiple-choice, numeric and list questions. Answer keys stay in a separate private teacher file. Offline submissions are marked as identity and timing unverified.

1. Choose a ready-made test or prepare your own

Ready-made test downloads follow the Test Bank’s existing access rules and do not use your custom exam-creation allowance. Custom Studio drafts remain multiple-choice in this version.

Enter a title, subject, multiple-choice questions, verified correct options and marks in the existing Studio. Set its Exam total to match. Then return here to create a fixed offline snapshot.

Custom Studio creation uses your existing exam allowance and newly counted questions allowance. Active trial, Pro or School access is required. Downloading an existing snapshot does not create another exam. A changed draft creates a new fixed version.

2. Download and distribute

Alternative JSON download and player

Open the generic offline player. Save that page before disconnecting, then open the exam JSON in it. The learner HTML option is simpler because it already contains its exam.

Give learners only the learner HTML file. Keep the PRIVATE key on the teacher’s device. Test the downloaded file offline on the devices your class will use.

3. Collect and reconnect

Learners submit in the offline file, then export their completed answer JSON. Collect those files. Sign in with the account that created the exam and upload them here when connected. The server re-marks from its stored answers and prevents the same attempt being counted twice.

These appear here as Offline Results, separately from existing live-exam submissions. Saved answer files are not sent automatically; the teacher uploads them. Result upload and viewing remain available for your own snapshots after package expiry.
Offline use, shared devices and supervision
  1. Download while online, then open the downloaded learner HTML file in a browser. No app installation is needed.
  2. Enter a learner code; name is optional. Each learner starts a separate attempt.
  3. Use Previous, Next and Review. Answers save in that browser where supported; export a backup regularly.
  4. Submit, export the completed answer file, and check it is saved before clearing for the next learner.
  5. For offline marking, open Teacher tools in the player and load the private key and answer files. Export provisional marks if needed. Upload original answer files later for a server re-mark.
Local-file storage and opening HTML vary by browser/device. Clearing browser data or private browsing can lose work. Use exported backups and test your school’s devices before an assessment. Keep learner files private. No passwords or Supabase keys are put into learner downloads.
Downloaded files can be copied and cannot be revoked or reliably expired while offline. Device time and learner identity are self-reported. This is suitable for supervised classroom assessment; it is not a tamper-proof high-stakes examination system.

  4. Use the answer guidance after the child tries. Praise the effort and repeat a small step if needed.

      What is STEAM?
      STEAM connects Science, Technology, Engineering, Arts and Mathematics through practical problems. Learners investigate, design, make, test and explain their ideas.
      • Science — investigate and explain what happens.
      • Technology — choose and use tools and techniques.
      • Engineering — design, build, test and improve a solution.
      • Arts — communicate and develop ideas through drawing, storytelling or purposeful design.
      • Mathematics — measure, calculate and interpret results.
      A classroom example — learners design a bottle watering device for seedlings, measure water use, compare results and draw instructions for another class.
      Start with a syllabus objective, a manageable challenge and available materials. Choose the STEAM skills that fit the lesson, then assess learners’ reasoning and evidence as well as their finished work.
      Try this sequence — ask a question, plan, make, test, improve and share.

      User Guide & Manual
      Learn how to use Education Lesedi Scholars Hub, step by step.
      
 
      Education Lesedi Scholars Hub by Lesedi Platforms
      Start with the guide for what you want to do. Tool availability depends on your account, current package and the resources available for your selection.
      
 
      English Explorers
      Open Learn & Practise or Teaching Studio, then English Explorers. Choose a class. Read or listen with a teacher, complete picture talk and writing tasks, or answer the four objective digital questions. Print learner sheets and teacher guides separately.
      Three samples are included during an active trial. Subscriber packs share the monthly Explorer allowance with Little Explorers. Speaking and writing are not automatically graded. Printouts show Lesedi copyright and permitted-use terms, without a customer-name licence line.
      Shared Explorer monthly activity allowance
      Starter includes 5 new subscriber packs per monthly access period; Pro includes 15. School allowances are agreed and configured by Lesedi. Each collection has three trial samples outside the shared paid allowance. Open Little Explorers to see remaining unlocks.
      Confirm Unlock activity to use one slot. Learner and teacher pages share the same unlock. Reopening and reprinting use no extra slots while a paid subscription is active. Unused slots do not carry over. Printouts show Lesedi copyright and a teaching-use notice.
      Little Explorers: picture-based STEAM for Classes 1-3
      1. Open STEAM Education, then Little Explorers.
      2. Choose a class and open an available activity.
      3. Read the teacher guidance and safety notes before preparing the practical task.
      4. Print the learner sheet and teacher guide separately.
      Active trials include A Bridge for a Toy Animal, A Shelter for a Toy and A Gentle Watering Tool. Active paid subscribers unlock new packs within their monthly allowance; reopening unlocked packs uses no extra allowance. Practical work is discussed and observed; it is not automatically marked.
      Estimated package prices in another currency

      These are reference estimates, not live quotes or new payment methods. Your provider may apply a different rate and fees. Rates older than seven days stop producing estimates until the reference data is updated. Request payment details to confirm how to pay.
      International Resources: South Africa Grade 4 Mathematics
      1. Open Teaching Studio → International Resources.
      2. Choose the South Africa CAPS Grade 4 Mathematics starter lesson.
      3. Read the lesson plan or answer the digital practice. You may change answers before submitting.
      4. For paper use, select Printable exercise or Marking guide and use its print button. You can also save a PDF in the print dialog.
      The first resource is a free sample. It covers selected skills, not a complete course. Digital practice scores are shown on the device and are not stored in Results & Analytics.
      International requests, class names and paper sizes
      Grade, Year, Form and Standard are class-naming systems used in different places. Enter the exact class name used by your school; this does not claim that the levels are equivalent across countries.
      1. For resources, open Requests, choose Teaching resource / test and enter country, curriculum, class, subject, topic, objectives, marks and preferred format.

      4. Open a custom lesson plan, scheme or test draft. Use My teaching preferences to fill its country/curriculum fields, then enter the actual class level and objectives.
      5. Paste lesson objectives in the existing outcomes field. In schemes, enter Topic | Code | Objective lines, keeping codes unchanged. Review the resulting weekly outcomes.
      6. Saved custom lesson plans and test drafts retain their curriculum context. Existing ready-made BEC and STEAM collections keep their original labels.

If you need a resource for another curriculum, send a website request with its country, curriculum, level, subject and topic.
      
 
      Get started: register, sign in and find your tools
      1. Select Create account. Enter your details, choose the account type that describes you and complete registration.
      2. If email confirmation is requested, open the confirmation email and follow its instructions. Check your spam folder if it has not arrived.
      3. Use Sign in with your registered email and password. Use the password reset option if needed.
      4. Open the left menu to choose a tool. On a small screen, open the menu first. Your dashboard shows the package and usage information available for your account.
      5. A lock or Members - Subscribe to unlock means that item needs an eligible active package. Trial access does not unlock every resource.

      You do not need to paste a whole paper one question at a time. Number each main question clearly, keep answer options with their question, and review the results after importing.
      
 
      Softcopy Converter: extract a PDF, DOCX, text file or photo
      1. Open Softcopy Converter and choose your file. For photos, use good lighting, keep the page straight and include the full text.
      2. Enter a resource title and choose what you want to create.
      3. Select Read and extract document and wait for the status message.
      4. Read the extracted text against the original. Correct question numbers, missing words, mathematical signs and answer options. OCR may not preserve diagrams or page layout.
      5. If a scanned PDF does not extract correctly, select Run OCR on every PDF page and try again. The current converter uses English OCR, so check other-language text carefully.
      6. Select Continue with selected tool. You can also use Save to cloud library when signed in and available.
      Text extraction is not the same as creating digital questions. For a digital examination, continue to Examination Studio and import the numbered questions.
      
 
      Examination Studio: create and publish your own digital test
      1. Enter the assessment title and subject/class.
      2. Paste all your numbered questions into Question text, or send reviewed text from the converter.
      3. Select Import numbered questions. Use Add question for an individual question or an item the importer missed.
      4. Check every digital question, question type and answer option. Enter the accepted correct answer and marks using the question controls. Put source answer-key text in the separate answer-key field when useful; still verify the digital answer settings.
      5. Select Save examination draft. Preview the draft to check the learner experience.
      6. For an auto-marked exam, enter an exam total that matches the sum of the question marks. For example, 30 questions worth 2 marks each total 60 marks.
      7. Select Publish and get learner link. Share the link or access information shown after successful publication.
      “Import or add digital questions” means the digital question list is empty. Pasting text alone does not populate that list: select Import numbered questions first.
      Check the wording and accepted answers before publishing. Only use source material you have permission to use.
      
 
      Take an Exam: answer and submit a teacher’s test
      1. Open the learner link supplied by your teacher, or open Take an Exam and use the access information requested there.
      2. Read the instructions, total marks and any timing information displayed.
      3. Answer each question and use the available Previous and Next controls to review your answers before submission.
      4. Check that all required questions are answered, then submit. Read the score or result information provided.
      Use the correct link or code for the assessment. If it cannot be opened, check the details with the teacher or send a support request.
      
 
      Test & Examination Bank: use a ready-made test
      1. Open Test & Examination Bank.
      2. Select the available level or class and find a suitable test. Read its topic coverage and total marks.
      3. Choose digital answering or a print option where offered. Locked items require eligible access.
      4. For printing, open the question paper and use Print / Save PDF. Check paper size, page breaks and the cover page in print preview.
      5. Open the marking or answer guide separately when provided. Keep it separate from the learner paper.
      If the topic you need is missing, use Requests to ask about a suitable test. Requests for particular member resources may require a qualifying subscription.
      
 
      Botswana Exam Library / BEC Practice: digital or printable practice
      1. Open Botswana Exam Library, or use a BEC Practice Explore button in Packages & Payments.
      2. Select PSLE, JC (JCE) or BGCSE, then search for a subject or practice title.
      3. Check the topics, question count and suggested time. Open an available free sample or sign in with an activated pass for restricted sets.
      4. Select Answer digitally to work through questions. Use Previous and Next to review before submission; the result shows marks and the supplied answer explanations.
      5. Select Print test for a question paper or Print answer guide for the answers. A separate document opens; select Print / Save PDF there. Allow pop-ups for the website if the browser blocks the document.
      BEC Practice is listed at BWP 100 for 30 days. It covers the available practice catalogue, not other subscription tools. These are independent practice materials, not official BEC papers. A mixed practice is not a complete syllabus course.
      
 
      Lesson plans: prepare an editable lesson
      1. Open Scheme of Work, Lesson Plans & Exercises, then Create a Lesson Plan.
      2. Enter the topic, subject, class, level, duration, class size and any available materials or classroom needs.
      3. Enter the learning outcomes and source notes where useful. If your account has an approved syllabus option, load the appropriate objectives.
      4. Select Create editable lesson plan. Read and edit the activities, timing, resources and assessment to suit your class.
      5. Use the available save and Print / Save PDF controls. Use Find a class exercise for related practice.
      Keep official syllabus objective codes unchanged when using them; adapt your teaching activities around the selected objectives.
      
 
      Schemes of work: plan the term and prepare a printable test
      1. Open the scheme planner and enter the subject, class, term and number of weeks.
      2. Enter topics one per line, or load the syllabus topics if that option is available for your account.
      3. Select Build scheme table. Review and edit the weekly outcomes, activities, resources and assessment.
      4. Use the provided print or save options. Where saved-term controls are available, follow the on-screen instructions; browser-saved terms belong to that browser/device.
      5. To prepare a question paper, expand Create a printable test from your scheme. Select the available coverage and settings, total marks and question style.
      6. Complete the cover page details and topics covered. Review the generated questions and guide before printing.
      
 
      Quick Class Exercises, Learning Notes and topic resources
      1. Open Quick Class Exercises from the planning area to find practice by the available level, subject and topic.
      2. Read the objective or coverage, open an exercise and use the digital or print controls offered.
      3. Use Learning Notes to read explanations and worked examples and try the available practice.
      4. Use Create from a Topic, Subject Question Bank or Teaching Resources for the resources offered to your account. Select the level, subject and topic before opening or generating material.
      5. Read any locked-access or unavailable-content message. Send a request if the material you need is missing.
      The catalogue varies by subject and level; a listed tool does not guarantee that every possible topic is already available.
      
 
      Writing Marker: photograph writing and get suggested marks
      1. Open Writing Marker from the Overview screen.
      2. Choose the available writing type and enter the assignment requirements.
      3. Enter your marking criteria and maximum marks, one per line. If using a rubric photo, select it and use Read rubric photo, then correct the extracted criteria.
      4. Take clear photographs of the learner’s writing in page order. Cover the learner’s name and real addresses. Select each photo and choose Add page.
      5. Select Read photos and suggest marks. Wait for the response, then review the recognised writing, proposed marks and feedback.
      6. Use the review and approval controls provided. Device-saved rubrics and approved results should be copied or exported where available if you need your own retained record.
      Suggested marks require your review. Available writing types, AI access and allowances are shown in the tool.

      Requests, support and the Professional Forum
      1. Open Requests & Replies to send a request and read your own request history and replies. Customers use their own messages; admin controls appear only where authorised.

      Saved work, results, schools and common problems
      • My Resource Library: sign in with the account used to save the document or draft. Look in the relevant saved-work section.
      • Results & Analytics: open the available result and reporting views for your account. A printable paper completed offline does not automatically send its marks to the website.
      • School & Classes: use the setup and class controls available for your authorised school account. Contact support if the required access is missing.
      • Print will not open: allow pop-ups, try the print button again and check the browser’s print preview. Choose Save as PDF if you want a file.
      • Incorrect extracted words: use a clearer image, try PDF OCR where appropriate and correct the text before importing questions.
      • Cannot preview or publish: check that digital questions exist, accepted answers are entered, marks match the total and your account has access.
      • Paid but still locked: confirm that you are signed in with the intended account, then send your payment reference through a website request.
      • Back navigation: use the available Back control or choose the desired menu option. Save work before leaving an editable draft.
