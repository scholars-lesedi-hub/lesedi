Help · Backup, privacy and reconnecting

For a refresh or accidental closure, reopen the SAME file in the SAME browser and choose Resume. Storage support for local files varies by device. If no saved attempt appears, restore your exported backup. Private/incognito mode and cleared browser data can remove local work.

To hand in: select Submit offline attempt, then Export completed answers. Transfer the JSON file by your school’s chosen method. When online, the teacher signs into the original account, opens Offline Examination Centre and uploads the file. This player does not automatically send results or store passwords.

Learner codes, optional names and answers stay in this browser and any exported files until the teacher uploads them. Use codes where possible; keep devices and files private. No location, camera or microphone is used.

A downloaded file cannot be revoked or made tamper-proof. Learner identity and device times are self-reported; use classroom supervision for controlled exams. No automatic subscription expiry check runs offline.
